# Limes visual docs

This Storybook is the living spec for designers and engineers. Open a component’s **Overview** first — it explains what the piece is for, which states exist, and how to use it. Then step through the named states.

## How to read it

1. **Foundations** — buttons, fields, checkboxes, upload, and the account layout.
2. **Dashboard** — SIM cards, plans, bundles, history, and the package wizard.
3. **Payment** — saved cards, top-up, shipping, and subscription management.
4. **Marketing** — homepage sections (hero, trust, packages, footer).

The canvas is a white spec sheet so product UI (especially dark dashboard chrome) stands out. Full-width pieces such as nav, hero, and modals still go edge to edge.

Light is the default background. Switch to Dark in the toolbar when you need to check a piece against the live app chrome.
